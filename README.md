# Zerodha Clone – MERN Stack

A full-stack Zerodha-inspired trading platform built using the MERN stack.  
This project focuses on authentication, dashboard design, and production-ready deployment.

## 🚀 Live Demo
https://zerodha-clone-one-alpha.vercel.app/

## 🛠 Tech Stack
- Frontend: React.js
- Dashboard: React.js (separate application)
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT (HTTP-only cookies)
- Deployment: Vercel & Render

## ✨ Features
- User Signup, Login & Logout
- JWT-based secure authentication
- Separate landing page and dashboard apps
- Dashboard modules:
  - Holdings
  - Positions
  - Orders
  - Watchlist
- Responsive UI inspired by Zerodha Console
